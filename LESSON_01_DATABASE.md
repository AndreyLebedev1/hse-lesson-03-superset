# Урок 1. От CSV до PostgreSQL

Цель урока — увидеть весь путь до BI-системы: источник данных, загрузчик,
реляционная база и независимая проверка результата.

## Результат

К концу урока:

- пять исходных CSV Olist загружены в PostgreSQL;
- исходные таблицы находятся в схеме raw;
- представление analytics.olist_items подготовлено для BI;
- каждая строка и каждое значение сверены с CSV;
- к базе можно подключиться из терминала и DBeaver.

## Запуск

    python3 scripts/run_lesson_01.py

Сценарий последовательно выполнит шаги 00–04. Каждый шаг можно запустить
отдельно; подробности приведены в README.md.

## Что посмотреть в DBeaver

Параметры соединения:

| Поле | Значение |
|---|---|
| Host | localhost |
| Port | 5433 |
| Database | olist |
| Username | olist_admin |
| Password | olist_local |

После подключения выполните запросы из sql/dbeaver_checks.sql.

Главный вопрос перед вторым уроком: почему BI-система подключается к
analytics.olist_items, а не строит каждый график непосредственно по пяти CSV?
