# План занятия: два урока по 80 минут

## Урок 1 — как данные доходят до BI

| Время | Содержание |
|---:|---|
| 0–10 | Где применяется BI: регулярные метрики, мониторинг, исследование, единая версия показателя |
| 10–20 | Обзор классов инструментов: таблицы, ноутбуки, BI, продуктовая аналитика; место Superset |
| 20–30 | Архитектура стенда: CSV → загрузчик → PostgreSQL → семантический слой → график |
| 30–40 | Шаги 0–1: проверка среды, скачивание Olist, контрольные суммы |
| 40–55 | Шаг 2: PostgreSQL, контейнер, порт, база и схема |
| 55–70 | Шаг 3: транзакционная загрузка пяти таблиц и представление analytics.olist_items |
| 70–80 | Шаг 4: автоматическая сверка; просмотр raw и analytics в DBeaver |
